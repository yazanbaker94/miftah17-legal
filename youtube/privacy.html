Privacy Policy

Miftah17 - Updated 2 November 2026

This policy describes Google and YouTube data used by Miftah17, a private tool operated by Miftah 17 Studios for its own channel.

Data accessed and why

  • Channel identifiers and channel information: to confirm that requests address the intended channel.
  • Video files, titles, descriptions, thumbnails, settings, processing status and scheduled publication times: to publish the owner's content and verify the result.
  • Comment text, comment identifiers and associated public author information: for owner-requested review, replies or moderation on the studio's channel.
  • OAuth access and refresh tokens: to make the Google API requests the owner has authorized.

The tool requests YouTube upload, read-only and management permissions. It does not request access to Gmail, contacts or Google Drive. Google handles account sign-in; the tool does not collect the account password.

Storage and use

Authorization credentials and working records are stored on the studio's owner-controlled computer. The operator may retain publishing receipts and relevant API responses for verification and future work. Credentials are excluded from public source code and public web pages.

Videos and their metadata are sent to Google/YouTube as needed for the requested upload or update. Google API data is used for the tool's publishing and channel-management functions, not sold, supplied to advertisers, or used by this tool to train general-purpose AI models.

Use and transfer of Google API data follows the Google API Services User Data Policy, including its Limited Use requirements.

Revocation and deletion

The owner can revoke access through Google Account permissions and delete locally stored credentials and records. Revoking access stops future authorized API requests; it does not delete videos already uploaded to YouTube. The channel owner can manage those videos in YouTube Studio.

For questions or requests to delete records held by the tool, contact the operator through the Miftah 17 Studios Facebook Page.
